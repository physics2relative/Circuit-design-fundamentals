# Analog Design

Analog 영역은 아직 공개 가능한 회로 파일과 측정 결과가 없는 계획 단계이다. 완료된 프로젝트처럼 여러 placeholder를 나열하지 않고, Virtuoso/Spectre로 검증할 순서를 하나의 roadmap으로 관리한다.

## Current Status

- Lifecycle: planned
- Public circuit/netlist: 없음
- Reproducible result: 없음
- Next lab: common-source amplifier DC/AC/transient characterization

## Roadmap

[Analog Simulation Roadmap](./ROADMAP.md)에서 회로별 목적, simulation 종류와 결과 기록 기준을 확인한다.

PDK, model, Cadence library database, generated netlist와 raw result는 공개하지 않는다. 공개 가능한 회로도, 조건, 핵심 측정값과 plot이 준비된 뒤 각 항목을 독립 프로젝트로 승격한다.

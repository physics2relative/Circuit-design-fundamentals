## Documentation Rule

외부 자료를 그대로 복사하지 않고, 프로젝트에서 확인할 가설, 조건, 관찰 결과와 한계를 직접 작성한다. PDK, model, license-gated document와 proprietary output은 저장소에 포함하지 않는다.
